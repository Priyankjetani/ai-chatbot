# AI Chatbot 🤖

A multi-model AI chatbot built with Flask + Python.

## Features
- ChatGPT (OpenAI)
- Claude (Anthropic)
- Gemini (Google)

## Setup
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Create `.env` file and add your API keys
4. Run: `python app.py`

## Tech Stack
- Python / Flask
- HTML, CSS, JavaScript
- Anthropic API, Google Gemini API, OpenAI API
